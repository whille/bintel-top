bintel · AI 视频笔记

Chrome 扩展:从 B 站 / YouTube / 抖音提取字幕并生成 AI 总结。

使用方法

  1. 从 Chrome Web Store 搜索 "bilibili subtitle extractor" 安装扩展
  2. 首次打开扩展自动注册,获得 50 点配额
  3. 打开任意 B 站视频页面,点扩展图标生成 AI 笔记
  4. 余额不足时在扩展内扫码充值(微信支付 ¥1 起步)

配额说明

  • 初始 50 点,可处理约 10 个 30 分钟视频的 AI 总结
  • 每次 cache miss 扣 1 点,命中缓存免费
  • Access Key 16 hex 跨设备同步配额
